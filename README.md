# Invoice / Email Triage Agent (synthetic demo)

**Portfolio demo** — agent loop that triages inbound invoice-related email into actions. All messages are fake.

## What it shows

1. Pull a synthetic inbox of invoice / billing emails
2. Agent loop: read → classify → propose action → log decision
3. Human-readable triage pack (approve / request info / escalate)

## Hard rules

- **Synthetic data only** — no real firm, client, or mailbox content
- Demo of an ops+AI workflow pattern, not a production mailbox bot
